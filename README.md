One line: the museum label a museum in the year 3000 puts beside an ordinary object from today — a shopping cart whose fourth wheel never turned.

**Entry (91 characters, 1 line):**

> Shopping Cart, c. 2023. Its fourth wheel never turned. Scholars agree this was intentional.

The label is pre-written in `entry.txt`; `main.py` only copies it to the grader's output directory, unchanged. It runs with the standard library only, deterministically, in two runs that produce byte-identical output.
